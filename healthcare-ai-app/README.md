# AI ஆரோக்கிய பராமரிப்பு ஆப் / AI Healthcare App

A simplified healthcare application with Tamil as the default language, supporting Tamil and Hindi.

## ✨ முக்கிய அம்சங்கள் / Key Features

### 🏥 அப்பாயிண்ட்மெண்ட் பதிவு / Appointment Booking
- மருத்துவர்களுடன் அப்பாயிண்ட்மெண்ட் பதிவு செய்யுங்கள்
- Book appointments with doctors
- View upcoming and past appointments
- Multiple specialty doctors available

### 💊 மருந்து டெலிவரி / Medicine Delivery
- மருத்துவர் சீட்டு அடிப்படையில் மருந்து ஆர்டர்
- Order medicines based on prescription
- Upload prescription images
- Home delivery from nearby pharmacies
- Track medicine orders

### 🍽️ ஊட்டச்சத்து / Nutrition
- தினசரி உணவு திட்டம்
- Daily meal plans with Tamil food items
- Water intake tracking
- Nutrition tips and calorie counting

### 📋 ஆரோக்கிய கண்காணிப்பு / Health Tracking
- Basic vital signs tracking
- Activity monitoring
- Simple health data input

### 🛡️ காப்பீடு / Insurance
- Basic insurance claim tracking
- Policy information display
- Claim status monitoring

### ⚙️ அமைப்புகள் / Settings
- Language switching (Tamil ↔ Hindi)
- Profile management
- Notification preferences
- 24/7 customer support

## 🌐 மொழி ஆதரவு / Language Support

- **தமிழ் (Tamil)** - Default language
- **हिंदी (Hindi)** - Secondary language
- Easy language switching in settings

## 🔔 நினைவூட்டல்கள் / Notifications

- 💧 Water intake reminders
- 💊 Medicine reminders  
- 🏃‍♂️ Exercise reminders
- 📅 Appointment reminders

## 🚀 Getting Started

1. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`

2. Start development server:
   \`\`\`bash
   npm run dev
   \`\`\`

3. Open http://localhost:5173 in your browser

## 📱 Features Overview

- **Simple UI Design** - Clean and minimalistic interface
- **Mobile Responsive** - Works on all device sizes
- **Native Language Support** - Tamil and Hindi interface
- **24/7 Customer Support** - Available in native languages
- **Prescription-based Medicine Delivery** - Safe and reliable
- **Easy Appointment Booking** - Simple booking process

## 🛠️ Technology Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Internationalization**: react-i18next
- **Notifications**: React Hot Toast
